# Midi3octaves

My midi is mainly for jazz music when a jazz organ is required.  My design features 4 customisable faders which could do functions such as volume, speaker pan, EQ etc etc. My midi also features 3 FX buttons for distortion and 2 rotary encoders. All of this is connected to my STM32 discovery which will be programmed in python. Most importantly, my midi includes 36 standard key buttons used for the keyboard in a space effective way.  

 I tried to make my midi as small as possible whilst maintaining 36 keys hence why I am just using standard keycaps on the buttons
